# java-practice

Учебный репозиторий: решения задач по Java в рамках подготовки к позиции
SDET (Software Development Engineer in Test).

## Структура

Все решения лежат в папке `src/`: одно задание — один класс с методом `main`.
Файлы с `V2` / `New...` в истории коммитов — повторные решения по новой
версии задачника.

## Решённые главы

### Глава 1 — Основы Java: переменные, условия, циклы, массивы, методы

| Файл | Что делает |
|---|---|
| `HelloQA.java` | первая программа: вывод приветствия в консоль |
| `PassportTestEnv.java` | «паспорт» тест-окружения: все примитивные типы + String в виде отчёта |
| `TestRunResults.java` | вердикт по тест-рану по проценту прохождения, с защитой от деления на ноль (?) |
| `TestTimeStat.java` | статистика времени тестов: минимум, максимум, среднее, число медленных |
| `PasswordValidator.java` | валидатор пароля: каждая из 4 проверок — отдельный метод |
| `TestIdGenerator.java` | генерация 30 случайных ID тестов, поиск и удаление дубликатов (v1) |
| `NewTestIdGenerator.java` | то же через массив-счётчик и массив без дубликатов (v2) |
| `TestRunAnalyzer.java` | консольный анализатор тест-рана (v1) |
| `ConsoleTestRunAnalyzer.java` | анализатор тест-рана (v2): статистика по классам, худший класс, прогресс-бар |

#### Тренировочные задачи (дрилы)

| Файл | Что делает |
|---|---|
| `DiceRolls.java` | 15 бросков кубика, частота каждой грани |
| `GradeMode.java` | мода среди 25 оценок, все значения при ничьей (v1) |
| `GradeModeFinder.java` | мода оценок с самопроверкой суммы счётчиков (v2) |
| `DigitCounter.java` | числа, встретившиеся ровно 2 раза, и количество уникальных |
| `DigitOccurrencesAnalyzer.java` | анализ вхождений цифр 1–9 в 40 случайных числах |
| `UniqueCharFinder.java` | первая неповторяющаяся буква в строке (массив на 26 букв) |

## Как запустить

Нужен JDK 17+. Из корня репозитория:

    java src/HelloQA.java
